# 使用与开发

## 当前功能

阶段 2 提供游戏内控制台面板、实时日志列表、日志筛选与历史查询、三种显示/输入模式、输入历史、命令补全、日志自动展开叠加层、内置服务端命令模式、专用服务器混合模式与 Cloth Config 配置界面。自动预览在后续阶段接入。

## 安装

使用目标 Minecraft 版本对应的 Fabric 或 NeoForge，以及对应平台的 Architectury API 和 Cloth Config。Fabric 还需要 Fabric API 和 Fabric Language Kotlin；NeoForge 需要 Kotlin for Forge 6.5.0。安装 Mod Menu 后可在模组列表中打开本模组的配置页面，NeoForge 可直接在模组列表中点击本模组的配置按钮。具体依赖版本以 [gradle.properties](../gradle.properties) 为准。

将对应平台 `build/libs/` 中不带 `dev` 或 `sources` 分类后缀的 JAR 放入客户端的 `mods/` 目录。客户端功能需要客户端安装；专用服务器的混合模式与命令鉴权需要服务端也安装本模组与 Cloth Config，服务端配置保存在 `config/ingamecnl-server.json`。普通远程服务器没有本模组时，客户端命令模式显示不可用。

## 打开与关闭

按反引号键打开控制台，主菜单、世界选择、聊天框、物品栏和游戏中均可使用。可以在“选项 → 控制 → 按键绑定 → 游戏内控制台”中修改开关、向上翻页、向下翻页和回到底部四个按键，支持键盘键与鼠标按钮；正在录入新绑定时，按键设置优先接收输入。Shift+Tab 固定用于切换模式，Esc 固定用于关闭控制台，不占用按键设置条目。

首次打开以仅查看模式显示：面板从屏幕顶部展开，默认占约 50% 的高度，不显示输入框和关闭按钮，游戏继续接收键鼠输入。世界中鼠标保持抓取；存档外鼠标点击穿透叠加层。按 Shift+Tab 进入日志或命令模式后，鼠标与键盘输入由面板接收。

按 Esc、在仅查看模式再次按控制台热键，或在日志/命令模式点击右上角关闭按钮收起面板。日志与命令模式下波浪键作为普通字符写入输入框，不会收起面板；仅查看模式下波浪键开关叠加层。进入世界时面板保持展开，不会自动收起。展开与收起从屏幕顶部匀速滑动，三种模式共用配置中的动画时长。仅查看模式首次打开会播放滑入，从该模式切换到日志或命令模式时面板直接以展开状态出现，不重复播放动画。收起途中可用热键反向展开。收起完成后恢复打开前的界面及其输入状态；从游戏中直接打开时恢复游戏输入。同一客户端启动期间，关闭后重新打开会恢复上次所处模式与未提交输入；客户端重启后回到默认的仅查看模式。面板高度和不透明度同样由三种模式共用。

日志自动展开是独立的只读叠加层。总开关默认开启；可见日志同时满足触发级别和触发关键词时从屏幕顶部展开，默认占 25% 高度并停留 3 秒，期间再次命中会重新计时。它不显示标题、输入框、状态行和底部提示，不接收其他叠加层交互；手动打开控制台、仅查看面板或配置界面时不会自动展开。默认按 Esc 可提前收起，收起后进入默认 30 秒静默期，期间不再自动展开；Esc 收起与静默期均可在配置中调整，静默期为 0 时禁用。关闭 Esc 收起后，Esc 直接作用于游戏，叠加层只在停留时间结束后收起。触发级别默认为 WARN，关键词为空表示不限制；高度、停留时间和关键词可在配置中调整，也可在日志模式执行 `autosplash filter <文本>` 设置关键词。

## 输入模式

| 模式 | 前缀 | 当前行为 |
| --- | --- | --- |
| 仅查看 | 无 | 默认模式；显示实时日志，游戏继续接收键鼠输入 |
| 日志模式 | `$` | 显示实时日志；接收 `filter`、`autosplash filter` 与 `grep` 命令 |
| 命令模式 | `#` | 在内置服务端执行命令，显示输入与反馈时间线 |
| 混合模式（专用服务器） | `>` | 显示服务端日志与命令时间线；命令行以 `:` 开头时执行本地 `:filter`/`:grep` |

按 Shift+Tab 在仅查看、日志、命令三种模式间循环；连接已完成握手的专用服务器时，命令模式显示为黄色的混合模式。日志与命令模式的输入行右侧显示 Shift+Tab，较窄窗口只显示该提示并为提示预留空间；仅查看模式在叠加层底部显示同一提示。每次按下只切换一次，长按不连续切换。前缀固定显示在输入框左侧，不属于输入内容。日志与命令模式各自保留草稿，关闭再打开面板时仍可继续编辑；调整窗口大小不会清空输入。输入行聚焦时按 ↑/↓ 调取本次客户端启动期间的提交历史，↓ 越过最新一条后恢复尚未提交的当前输入；空白输入和与上一条完全相同的重复输入不写入历史。

日志与命令模式在输入时展开候选列表，复用原版命令补全：日志模式补全 `filter`、`autosplash`、`grep` 及其参数，命令模式补全服务端命令与参数，混合模式下以 `:` 开头的输入补全 `:filter`、`:grep`。列表从输入行下方展开，最多 8 行，超出部分在列表内滚动；面板高度超过 90% 时不再展开列表，翻页键改为翻动时间线。

专用服务器补全的命令树按服务端自身权限下发，与客户端玩家的游戏权限无关，非管理员玩家同样能看到 `gamemode`、`op` 等全部服务端指令。日志模式的本地命令不带冒号，混合模式的本地命令必须带 `:`；不带 `:` 的输入按服务端命令补全，带 `:` 的输入只补全本地的 `:filter` 与 `:grep`。

| 按键 | 作用 |
| --- | --- |
| Tab | 采纳当前候选项；再次按下在候选中循环 |
| Shift+Tab | 切换模式 |
| ↑ / ↓ | 列表展开时在候选中上移 / 下移；列表收起时翻阅提交历史 |
| Esc | 列表展开时先收起列表 |
| PageUp / PageDown | 列表展开时在列表内滚动，否则翻动时间线 |
| 鼠标滚轮 / 点击 | 在列表内滚动 / 直接采纳某一行 |

输入行沿用原版聊天栏的着色规则：已输入的命令字面量显示为灰色，各个参数依次使用水蓝、黄、绿、淡紫、金色轮换，解析器还没读完的部分显示为红色。没有候选项时，输入行下方会显示原版的错误与用法提示，例如缺少参数、数值越界或未知参数，以及当前位置可用的写法；同一行按面板宽度限制，最多显示到面板底部。按 Enter 后具体错误原因仍写入时间线。

仅查看模式不显示输入框，波浪键开关叠加层，Esc 隐藏叠加层，翻页键与回底键滚动日志，Shift+Tab 进入日志模式。世界中鼠标保持抓取，移动、视角和攻击/使用继续作用于游戏；存档外叠加层不拦截鼠标，点击直接作用于下层界面。

命令模式始终保留在三种模式的循环中。按 Enter 将输入的命令交给当前内置服务端执行，执行源是服务端控制台，因此不要求存档开启作弊，也不受玩家游戏模式限制。输入、命令反馈和错误按顺序进入命令时间线；PageUp/PageDown、End 与滚轮滚动时间线，关闭面板或退出世界时清空。命令不会自动加上 `/`，直接输入 `time set day` 即可。

单人存档对局域网开放后，其他客户端默认不能使用命令模式。主机可在配置的“单人游戏”分类中允许远程使用，并按玩家名或 IP 选择白名单或黑名单；主机本人始终可用。非主机客户端需要安装本模组，通过主机模组通道请求执行；主机每次执行前重新校验权限，输出只回传给请求者。局域网环境仍叫命令模式，不使用混合模式，也不推送服务端日志。

专用服务器使用独立的 `config/ingamecnl-server.json`，默认关闭命令模式。启用后，服务端按白名单或黑名单校验请求者的玩家名、UUID 与 IP；白名单为空时不授权任何玩家，黑名单为空时拒绝所有玩家。服务端默认每秒最多 20 次请求、最小间隔 200 毫秒、会话令牌 300 秒有效，并记录审计日志。管理员可执行 `/ingamecnl commandmode status|on|off|reload` 查看或切换开关、重新加载配置，需要管理员权限。开启静默模式用 `/ingamecnl commandmode silent on`，关闭用 `silent off`。客户端连接后先完成能力握手，拿到短期令牌才显示黄色的混合模式；令牌过期会自动重新请求。执行 `commandmode on|off|reload` 后服务端会立即向在线玩家重新下发能力，客户端收到后重新握手并按新状态刷新订阅。

静默模式用于防止未授权客户端察觉服务端装有本模组。开启后，未通过名单校验的玩家不会收到任何能力响应、命令结果或服务端日志，命令树中也不含 `/ingamecnl`；对方看到的效果与未安装本模组的原版服务器一致。已授权玩家不受影响，仍可握手、执行命令和接收日志。该模式只作用于未授权客户端，不改变通道注册；Fabric 与 NeoForge 都在玩家加入时一次性下发全局通道表，无法按玩家裁剪，因此装有本模组的客户端仍能从通道列表看到服务端装有本模组。静默模式隐藏的是握手结果、命令节点、命令结果与日志内容。开关保存在 `config/ingamecnl-server.json` 的 `silent`，也可用 `/ingamecnl commandmode silent on|off` 在线切换；静默期间该命令只对服务端控制台与已授权管理员可用。切换后已建立的会话会被重置，在线玩家重新握手。

混合模式的内容是单一时间线，服务端日志、玩家聊天与加入/退出、命令输入和命令输出按到达顺序混排在同一区域，接近服务器终端。日志由服务端独立捕获并按序推送，首次订阅发送最近 10,000 条，之后每 tick 最多 256 条/64 KiB；客户端断线或序号缺口时重新同步。命令执行结果、失败原因与 `:filter`/`:grep` 的提示都写入同一时间线并常驻，不再使用一闪而过的状态行文本。日志区域用 PageUp/PageDown、滚轮滚动，End 回到底部，输入框为空时 Home 跳到顶部，上翻后状态行显示“新增 N 条”，新记录到达时保持当前阅读位置。输入不以 `:` 开头时作为服务端命令执行；以 `:` 开头时只在本机处理，支持 `:filter` 与 `:grep`。`:filter` 只影响混合模式后续到达的服务端日志，隐藏的记录仍保留在原始缓冲区，状态行显示当前规则与显示/隐藏计数；`:grep` 对已接收的完整服务端日志原始缓冲区建立固定快照后扫描，隐藏记录仍可被搜到。服务端日志不进入本地日志历史，也不会触发日志自动展开。

> **安全提示**：服务端日志流会把服务端进程日志的原文推送给已授权客户端，其中可能包含玩家 IP、文件系统路径、聊天内容以及其他 Mod 的输出。白名单只应包含可信玩家；不确定时请关闭 `logStreamingEnabled`。

普通远程服务器没有本模组时，客户端命令模式仍显示不可用。

日志模式按 Enter 提交 `filter`、`autosplash filter` 或 `grep` 命令；命令模式按 Enter 提交服务端命令；混合模式按 Enter 提交服务端命令，输入以 `:` 开头时改在本机执行 `:filter` 或 `:grep`。

## 日志视图与筛选

日志列表按接收顺序编号，每行格式为 `序号 [时间] [线程/级别] (logger) 消息`。默认沿用 Loom 控制台配色：时间蓝色，线程与级别按级别着色（ERROR、FATAL 红色，WARN 黄色，INFO、DEBUG 绿色，TRACE 蓝色），logger 青色，ERROR、FATAL 的消息红色；时间、级别、logger 和消息颜色均可在配置中修改。方括号和圆括号按普通文本显示。

消息超过一行宽度时自动换行，续行不重复序号；单条记录最多显示 8 行，未显示完的消息和异常在末行以 `…` 结尾。面板打开时跟随最新记录。在日志区域向上滚动（滚轮、PageUp）后视图保持位置，新记录到达时状态行右侧显示“新增 N 条”；点击该提示或按 End 回到底部。PageDown 向下翻页。

底部状态行显示当前筛选条件和“显示 / 淘汰 / 丢弃”计数。淘汰来自历史容量上限，丢弃来自接收队列已满。

日志模式支持以下命令，大小写不敏感：

| 命令 | 作用 |
| --- | --- |
| `filter level <级别>` | 后续只显示精确匹配该级别的记录 |
| `filter keyword <文本>` | 后续只显示消息或异常文本包含该文本的记录，忽略大小写 |
| `filter reset` | 清除全部显示筛选 |
| `filter reset level` | 仅清除级别筛选 |
| `filter reset keyword` | 仅清除关键词筛选 |
| `filter show` | 显示当前筛选状态 |
| `autosplash filter <文本>` | 设置自动展开的触发关键词；文本可包含空格，留空会报错 |

筛选只影响命令提交后接收的记录；已经显示的内容保持不变。命令错误以红色提示显示并保留输入，成功后清空输入。日志记录仍保留有界原始历史，筛选不会删除隐藏记录。

## 历史查询

`grep` 在当前原始日志历史中查询，不受实时显示筛选影响。命令格式为 `grep -k <关键词> -l <级别> [-t1 <开始>] [-t2 <结束>]`，选项顺序可调整，`-k` 与 `-l` 必填。关键词在消息和异常文本中做忽略大小写的子串匹配；级别精确匹配；时间上下界均包含端点，所有条件按交集组合。

带空格的关键词或时间使用双引号，例如：

```text
grep -k "failed to load" -l WARN
grep -k tick -l ERROR -t1 12:00:00 -t2 12:30:00
grep -k world -l INFO -t1 "2026-11-22 12:00:00"
```

时间可用 `HH:mm:ss` 或 `YYYY-MM-DD HH:mm:ss`；短时间按提交当天补齐，使用本机时区。开始时间晚于结束时间、非法级别、未闭合引号、重复或未知选项、缺失值都会显示红色错误并保留输入。

提交后进入只读结果区。结果只包含提交那一刻的历史记录；之后到达的日志不会插入结果，也不会触发自动展开。顶部显示查询条件和实际可搜索的时间范围，底部显示当前位置和总数。按键：

| 按键 | 作用 |
| --- | --- |
| ↑ / ↓、滚轮 | 逐条滚动 |
| PageUp / PageDown | 翻页 |
| Home / End | 跳到首条 / 末条 |
| ← / → | 横向滚动长行 |
| q 或 Esc | 关闭结果区，恢复输入 |

结果区打开时输入暂停，Esc 优先关闭结果区而不是控制台。历史淘汰不会让结果跳动；结果读取期间其引用的记录保持可用，关闭后释放。没有匹配时显示空结果提示。

## 配置

Fabric 安装 Mod Menu 后，从模组列表中本模组的配置按钮进入 Cloth Config 配置页面；NeoForge 在模组列表中提供同名配置按钮。配置保存到客户端的 `config/ingamecnl.json`。

| 分类 | 项目 | 说明 |
| --- | --- | --- |
| 筛选 | 日志级别、关键词 | 与 `filter level`、`filter keyword` 使用同一规则；保存后只影响后续接收的记录 |
| 日志容量 | 日志条数上限、文本量上限 | 条数默认 2147483647，最大可填 9223372036854775807；文本量默认 128 MiB、范围 1～2048 MiB。达到任一上限时从最旧记录开始淘汰；条数极大时实际保留量主要受文本量上限约束 |
| 自动展开 | 总开关、触发级别、触发关键词、高度、停留时间、Esc 收起、静默期 | 总开关默认开启；触发级别默认 WARN，关键词为空表示不限制；高度 10%～100%，默认 25%；停留 500～10000 毫秒，默认 3000；Esc 收起默认开启；静默期默认 30 秒，范围 0～600 秒，0 为禁用。可见日志需同时满足级别和关键词才会触发，手动 Esc 收起后静默期内不再触发 |
| 颜色 | 时间、TRACE、DEBUG、INFO、WARN、ERROR、FATAL、logger、消息、错误消息 | 点击色块选择颜色，修改后立即用于新绘制的日志行 |
| 面板 | 高度、动画时长、不透明度 | 高度 30%～100%，默认 50%；动画 0～1000 毫秒，默认 180；不透明度 0%～100%，默认 10%。三项同时作用于仅查看、日志和命令模式，自动展开使用自己的高度 |
| 单人游戏 | 允许远程命令、名单模式、玩家名/IP 名单 | 仅对局域网开放的单人存档生效；默认不允许远程命令，名单模式默认白名单。白名单留空时不授权任何非主机客户端；黑名单留空且总开关开启时允许所有非主机客户端。玩家名忽略大小写，IP 精确匹配 |

在日志模式执行 `filter` 命令会同步更新配置中的筛选条件；执行 `autosplash filter` 会更新自动展开的触发关键词。仅查看、日志与命令模式共用“面板”的高度、动画时长和不透明度；自动展开只使用“自动展开”的高度，动画与不透明度仍取“面板”的值。

专用服务器配置独立保存在服务端的 `config/ingamecnl-server.json`，没有图形界面，修改后执行 `/ingamecnl commandmode reload` 或重启服务器：

| 项目 | 说明 |
| --- | --- |
| `enabled` | 命令模式总开关，默认 `false` |
| `silent` | 静默模式：对未授权玩家完全不发送本模组的数据包，默认 `false` |
| `accessMode` | `WHITELIST` 或 `BLACKLIST`，默认白名单 |
| `names` / `uuids` / `ips` | 玩家名、UUID、IP 名单；白名单为空时拒绝所有玩家，黑名单为空时同样拒绝所有玩家 |
| `maxRequestsPerMinute` | 每玩家每分钟最多命令请求数，默认 20 |
| `minIntervalMillis` | 两次请求的最小间隔，默认 200 毫秒 |
| `sessionTtlSeconds` | 能力令牌有效期，默认 300 秒 |
| `auditLog` | 是否把命令执行写入 `ingamecnl-audit` 日志，默认开启 |
| `logStreamingEnabled` | 是否向已授权客户端推送服务端日志，默认开启 |
| `logBacklogLines` | 首次订阅发送的历史条数，默认 10000 |

## 构建

使用与根 [build.gradle](../build.gradle) 中 `javaTarget` 一致的 JDK，使用项目 Gradle Wrapper：

```powershell
.\gradlew.bat :fabric:build :neoforge:build --console=plain
```

开发运行任务：

```powershell
.\gradlew.bat :fabric:runClient
.\gradlew.bat :neoforge:runClient
```

依赖变更后重新构建两端。Fabric 发布依赖 Fabric Language Kotlin；NeoForge 发布依赖 Kotlin for Forge，不打包 Kotlin 标准库。不要将 Kotlin 标准库另外展开进平台 JAR。

构建会在 `:common:processResources` 前调用 Zig 交叉编译 Windows、Linux、macOS 的 x86_64/aarch64 与 Android arm64 comb 加速库并打入发布 JAR；需要 [Zig](https://ziglang.org/) 0.17 或更高版本，`common/src/native` 的 `build.zig.zon` 固定 comb 提交。Android 目标额外需要 Android NDK，按 API 26（Android 8.0）构建；缺少 NDK 时只跳过 Android。没有 Zig 时跳过全部原生库，`grep` 自动使用 JVM 扫描；运行时按操作系统与架构选择对应库，Android 仅支持 arm64，缺失、加载失败或 JVM 不提供 FFM 时同样回退。Android arm64 已在 Android 17 / SM8850 / Fold Craft Launcher / Java 25 环境验证加载。

## 阶段 1 与阶段 2 操作检查

分别在两个加载器中进入世界，检查热键开关、Esc 与关闭按钮、开合动画、输入焦点、GUI 缩放和窗口大小调整；在日志/命令模式输入波浪键，确认字符进入输入框且面板不收起；在仅查看模式确认波浪键开关叠加层；进入世界时确认面板保持展开。按 Shift+Tab 循环三种模式并关闭再打开，检查恢复上次模式与日志/命令草稿保留，以及行尾提示不遮挡输入。

检查仅查看模式默认打开时世界仍接收移动、视角和攻击/使用；从主菜单、世界选择、聊天框和物品栏打开时，鼠标点击穿透叠加层并作用于原界面，翻页键与回底键仍可滚动日志，Shift+Tab 进入日志模式，Esc 隐藏叠加层。

在按键设置中改绑开关、翻页与回底键后重复上述操作。从主菜单、世界选择、聊天框和物品栏中打开并关闭面板，检查原界面、聊天草稿和容器状态恢复。连接未安装本模组的远程服务器时检查命令模式显示不可用提示；进入世界时检查面板保持展开。

检查日志列表持续更新、滚轮与 PageUp/PageDown 翻页、End 回底和新增计数。提交 `filter level`、`filter keyword`、`filter reset` 与 `filter show`，确认旧记录保持原样、后续记录按新规则显示，并检查非法命令的红色提示与草稿保留。在日志与命令模式分别用 ↑/↓ 调取历史，确认两个模式的历史独立、↓ 越过最新后恢复当前输入。

提交 `grep -k <关键词> -l <级别>` 以及带 `-t1`/`-t2` 的查询，确认结果只包含提交时的历史、后续日志不插入且不触发自动展开；检查关键词与级别交集、时间端点、引号与非法命令错误。在结果区检查 ↑/↓、滚轮、PageUp/PageDown、Home/End、←/→、q 与 Esc，确认 Esc 只关闭结果区、输入焦点恢复，历史淘汰不会让结果跳动。

在未开启作弊的单人存档中切换命令模式，执行 `time set day`、`give` 等命令，确认由服务端控制台执行、反馈进入时间线、错误反馈保留输入；退出世界后确认时间线清空。对局域网开放后，用非主机客户端验证默认拒绝、总开关、白名单与黑名单、玩家名和 IP 匹配；主机本人始终可执行。

在专用服务器安装本模组并保持 `enabled=false`，确认客户端只显示不可用；用 `/ingamecnl commandmode on` 开启并把客户端加入白名单后重连，确认命令模式显示黄色的混合模式、服务端日志按序出现、普通输入执行服务端命令、`:filter` 只影响后续服务端日志、`:grep` 能搜到被 filter 隐藏的记录。验证白名单为空、黑名单为空、令牌过期刷新、每分钟请求上限、退出重进后的日志补发和缺口重置；确认服务端日志不触发客户端日志自动展开。开启静默模式后，用不在名单中的玩家连接，确认其收不到任何能力响应、命令结果或服务端日志，命令树中也没有 `/ingamecnl`；名单内玩家仍可正常握手与执行命令。用不是管理员的玩家连接，确认候选列表仍能补全 `gamemode`、`op` 等全部服务端指令；确认混合模式输入 `:` 时只补全 `:filter`、`:grep`，不带冒号时补全服务端命令，日志模式只补全不带冒号的本地命令。

从 Fabric Mod Menu 或 NeoForge 模组列表的配置按钮检查配置页面可打开和保存；调整筛选后确认只影响后续记录，调整日志容量后确认超限时淘汰最旧记录，调整颜色、面板高度、动画时长和不透明度后确认三种模式的显示同时变化。

在世界中触发达到 WARN 的可见日志，确认自动展开默认 25% 高度、停留 3 秒，新命中重新计时；按 Esc 可提前收起，收起后默认 30 秒内不再自动展开；关闭 Esc 收起后确认 Esc 作用于游戏，叠加层按停留时间收起；其他键鼠不作用于该叠加层；手动打开控制台或配置界面时不会自动展开。调整触发级别、关键词、高度、停留时间、Esc 收起或静默期后确认行为相应变化；在日志模式执行 `autosplash filter` 设置关键词后，确认只有同时满足显示筛选、触发级别和关键词的可见日志触发自动展开。
