# 使用与开发

## 当前功能

阶段 1 提供游戏内控制台面板、热键、日志与命令模式切换，以及各模式独立的输入草稿。日志采集、自动预览、`filter`、`grep`、输入历史、补全和服务端命令执行在后续阶段接入。

## 安装

使用目标 Minecraft 版本对应的 Fabric 或 NeoForge，以及对应平台的 Architectury API。Fabric 还需要 Fabric API 和 Fabric Language Kotlin；NeoForge 产物已配置嵌入 Kotlin 标准库。具体依赖版本以 [gradle.properties](../gradle.properties) 为准。

将对应平台 `build/libs/` 中不带 `dev` 或 `sources` 分类后缀的 JAR 放入客户端的 `mods/` 目录。该模组提供客户端功能，远程服务器无需安装。

## 打开与关闭

按反引号键打开控制台，主菜单、世界选择、聊天框、物品栏和游戏中均可使用。可以在“选项 → 控制 → 按键绑定 → 游戏内控制台”中修改按键，支持键盘键与鼠标按钮；正在录入新绑定时，按键设置优先接收输入。

面板从屏幕顶部占约 65% 的高度；较小窗口会使用更多高度以容纳控件。背景不透明度为 10%，文字保持清晰，输入框和关闭按钮没有额外的不透明底色。打开面板时单人世界继续运行，鼠标与键盘输入由面板接收。

按 Esc、再次按控制台热键，或点击右上角关闭按钮收起面板。展开与收起从屏幕顶部匀速滑动，完整行程为 180 毫秒；收起途中可用热键反向展开。收起完成后恢复打开前的界面及其输入状态；从游戏中直接打开时恢复游戏输入。

## 输入模式

| 模式 | 前缀 | 当前行为 |
| --- | --- | --- |
| 日志模式 | `$` | 接收并保留本地日志命令草稿 |
| 命令模式 | `#` | 接收并保留内置服务端命令草稿 |

按 Shift+Tab 切换模式，输入行右侧显示切换提示；较窄窗口只显示组合键名称，并为提示预留空间。每次按下只切换一次，长按不连续切换。前缀固定显示在输入框左侧，不属于输入内容。两种模式各自保留草稿，关闭再打开面板时仍可继续编辑；调整窗口大小不会清空输入。

命令模式只在当前世界的内置服务端已就绪、正在运行且客户端连接有效时启用。存档外或连接远程服务器时，Shift+Tab 显示不可用提示并保留日志模式；服务端失效时自动返回日志模式。切换或退出世界时立即关闭面板。

当前按 Enter 只显示功能尚未接入的提示并保留草稿，不提交日志命令或服务端命令。筛选、历史查询和终端用法见[功能计划](plan/README.md)。

## 构建

使用与根 [build.gradle](../build.gradle) 中 `javaTarget` 一致的 JDK，使用项目 Gradle Wrapper：

```powershell
.\gradlew.bat :fabric:build :neoforge:build --console=plain
```

开发运行任务：

```powershell
.\gradlew.bat :fabric:runClient
.\gradlew.bat :neoforge:runClient
```

依赖变更后重新构建两端。Fabric 发布依赖 Fabric Language Kotlin；NeoForge 发布 JAR 通过 Jar-in-Jar 包含标准库。不要将 Kotlin 标准库另外展开进平台 JAR。

## 阶段 1 操作检查

分别在两个加载器中进入单人世界，检查热键开关、Esc 与关闭按钮、开合动画、输入焦点、GUI 缩放和窗口大小调整；按 Shift+Tab 切换模式并关闭再打开，检查两份草稿保留，以及行尾提示不遮挡输入。

在按键设置中改绑键盘键与鼠标按钮后重复开关操作。从主菜单、世界选择、聊天框和物品栏中打开并关闭面板，检查原界面、聊天草稿和容器状态恢复。存档外和连接远程服务器时检查命令模式禁用；退出或切换世界时检查面板关闭。
