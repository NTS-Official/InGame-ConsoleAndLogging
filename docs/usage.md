# 使用与开发

## 当前功能

阶段 2 提供游戏内控制台面板、实时日志列表、日志筛选、三种显示/输入模式和 Cloth Config 配置界面。`grep`、输入历史、补全、自动预览和服务端命令执行在后续阶段接入。

## 安装

使用目标 Minecraft 版本对应的 Fabric 或 NeoForge，以及对应平台的 Architectury API 和 Cloth Config。Fabric 还需要 Fabric API 和 Fabric Language Kotlin；NeoForge 需要 Kotlin for Forge 6.5.0。安装 Mod Menu 后可在模组列表中打开本模组的配置页面，NeoForge 可直接在模组列表中点击本模组的配置按钮。具体依赖版本以 [gradle.properties](../gradle.properties) 为准。

将对应平台 `build/libs/` 中不带 `dev` 或 `sources` 分类后缀的 JAR 放入客户端的 `mods/` 目录。该模组提供客户端功能，远程服务器无需安装。

## 打开与关闭

按反引号键打开控制台，主菜单、世界选择、聊天框、物品栏和游戏中均可使用。可以在“选项 → 控制 → 按键绑定 → 游戏内控制台”中修改开关、切换模式、向上翻页、向下翻页、回到底部、关闭控制台和打开配置七个按键，支持键盘键与鼠标按钮；正在录入新绑定时，按键设置优先接收输入。

默认以仅查看模式打开：面板从屏幕顶部展开，默认占约 65% 的高度，不显示输入框和关闭按钮，游戏继续接收键鼠输入。世界中鼠标保持抓取；存档外鼠标点击穿透叠加层。按 Shift + 切换键进入日志或命令模式后，鼠标与键盘输入由面板接收。

按关闭键（默认 Esc）、再次按控制台热键，或在日志/命令模式点击右上角关闭按钮收起面板。展开与收起从屏幕顶部匀速滑动，完整行程默认 180 毫秒；收起途中可用热键反向展开。收起完成后恢复打开前的界面及其输入状态；从游戏中直接打开时恢复游戏输入。叠加层高度、动画时长和不透明度可在配置中调整。

## 输入模式

| 模式 | 前缀 | 当前行为 |
| --- | --- | --- |
| 仅查看 | 无 | 默认模式；显示实时日志，游戏继续接收键鼠输入 |
| 日志模式 | `$` | 显示实时日志；接收 `filter` 命令 |
| 命令模式 | `#` | 接收并保留内置服务端命令草稿 |

按住 Shift 再按切换键，在三种模式间循环；切换键默认 Tab，可在按键设置中修改。日志与命令模式的输入行右侧显示 Shift + 切换键，较窄窗口只显示键名并为提示预留空间；仅查看模式在叠加层底部显示同一提示。每次按下只切换一次，长按不连续切换。前缀固定显示在输入框左侧，不属于输入内容。日志与命令模式各自保留草稿，关闭再打开面板时仍可继续编辑；调整窗口大小不会清空输入。

仅查看模式不显示输入框，关闭键隐藏叠加层，翻页键与回底键滚动日志，Shift + 切换键进入日志模式。世界中鼠标保持抓取，移动、视角和攻击/使用继续作用于游戏；存档外叠加层不拦截鼠标，点击直接作用于下层界面。

命令模式始终保留在三种模式的循环中。内置服务端未就绪、存档外或连接远程服务器时，状态行显示需要本地内置服务端的提示，命令仍可输入并保留草稿；按 Enter 只显示功能尚未接入的提示。切换或退出世界时立即关闭面板。

日志模式按 Enter 提交 `filter` 命令；命令模式按 Enter 只显示功能尚未接入的提示并保留草稿。

## 日志视图与筛选

日志列表按接收顺序编号，每行格式为 `序号 [时间] [线程/级别] (logger) 消息`。默认沿用 Loom 控制台配色：时间蓝色，线程与级别按级别着色（ERROR、FATAL 红色，WARN 黄色，INFO、DEBUG 绿色，TRACE 蓝色），logger 青色，ERROR、FATAL 的消息红色；时间、级别、logger 和消息颜色均可在配置中修改。方括号和圆括号按普通文本显示。

消息超过一行宽度时自动换行，续行不重复序号；单条记录最多显示 8 行，未显示完的消息和异常在末行以 `…` 结尾。面板打开时跟随最新记录。在日志区域向上滚动（滚轮、PageUp）后视图保持位置，新记录到达时状态行右侧显示“新增 N 条”；点击该提示或按 End 回到底部。PageDown 向下翻页。

底部状态行显示当前筛选条件和“显示 / 淘汰 / 丢弃”计数。淘汰来自历史容量上限，丢弃来自接收队列已满。

日志模式支持以下命令，大小写不敏感：

| 命令 | 作用 |
| --- | --- |
| `filter level <级别>` | 后续只显示精确匹配该级别的记录 |
| `filter keyword <文本>` | 后续只显示消息或异常文本包含该文本的记录，忽略大小写 |
| `filter reset` | 清除全部显示筛选 |
| `filter reset level` | 仅清除级别筛选 |
| `filter reset keyword` | 仅清除关键词筛选 |
| `filter show` | 显示当前筛选状态 |

筛选只影响命令提交后接收的记录；已经显示的内容保持不变。命令错误以红色提示显示并保留输入，成功后清空输入。日志记录仍保留有界原始历史，筛选不会删除隐藏记录。

## 配置

按打开配置键（默认 F8）可在任意界面打开 Cloth Config 配置页面；Fabric 安装 Mod Menu 后，也可从模组列表中本模组的配置按钮进入；NeoForge 在模组列表中提供同名配置按钮。配置保存到客户端的 `config/ingamecnl.json`。

| 分类 | 项目 | 说明 |
| --- | --- | --- |
| 筛选 | 日志级别、关键词 | 与 `filter level`、`filter keyword` 使用同一规则；保存后只影响后续接收的记录 |
| 颜色 | 时间、TRACE、DEBUG、INFO、WARN、ERROR、FATAL、logger、消息、错误消息 | 点击色块选择颜色，修改后立即用于新绘制的日志行 |
| 叠加层 | 高度、动画时长、不透明度 | 高度 30%～100%，默认 65%；动画 0～1000 毫秒，默认 180；不透明度 0%～100%，默认 10% |

在日志模式执行 `filter` 命令会同步更新配置中的筛选条件。仅查看叠加层使用配置的高度、动画时长和不透明度；日志与命令模式的面板高度、动画和背景保持内置值（65%、180 毫秒、10% 不透明度）。

## 构建

使用与根 [build.gradle](../build.gradle) 中 `javaTarget` 一致的 JDK，使用项目 Gradle Wrapper：

```powershell
.\gradlew.bat :fabric:build :neoforge:build --console=plain
```

开发运行任务：

```powershell
.\gradlew.bat :fabric:runClient
.\gradlew.bat :neoforge:runClient
```

依赖变更后重新构建两端。Fabric 发布依赖 Fabric Language Kotlin；NeoForge 发布依赖 Kotlin for Forge，不打包 Kotlin 标准库。不要将 Kotlin 标准库另外展开进平台 JAR。

## 阶段 1 与阶段 2 操作检查

分别在两个加载器中进入单人世界，检查热键开关、关闭键与关闭按钮、开合动画、输入焦点、GUI 缩放和窗口大小调整；按 Shift + 切换键循环三种模式并关闭再打开，检查日志/命令草稿保留，以及行尾提示不遮挡输入。

检查仅查看模式默认打开时世界仍接收移动、视角和攻击/使用；从主菜单、世界选择、聊天框和物品栏打开时，鼠标点击穿透叠加层并作用于原界面，翻页键与回底键仍可滚动日志，Shift + 切换键进入日志模式，关闭键隐藏叠加层。

在按键设置中改绑开关、切换、翻页、回底、关闭与打开配置键后重复上述操作。从主菜单、世界选择、聊天框和物品栏中打开并关闭面板，检查原界面、聊天草稿和容器状态恢复。存档外和连接远程服务器时检查命令模式显示不可用提示；退出或切换世界时检查面板关闭。

检查日志列表持续更新、滚轮与 PageUp/PageDown 翻页、End 回底和新增计数。提交 `filter level`、`filter keyword`、`filter reset` 与 `filter show`，确认旧记录保持原样、后续记录按新规则显示，并检查非法命令的红色提示与草稿保留。

按打开配置键检查配置页面可打开和保存；调整筛选后确认只影响后续记录，调整颜色、叠加层高度、动画时长和不透明度后确认显示变化。Fabric 安装 Mod Menu 时，从模组列表打开本模组配置页面并重复检查；NeoForge 从模组列表的配置按钮重复检查。
