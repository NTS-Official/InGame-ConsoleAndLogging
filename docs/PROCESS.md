# 开发进度

阶段 1、阶段 2 与历史查询的代码已落地，Fabric 和 NeoForge 的完整构建均已通过。Fabric 开发客户端已确认默认仅查看叠加层、日志模式与命令模式界面可显示，配置页面已接入且配置文件、Fabric Mod Menu 与 NeoForge 模组列表配置入口已就绪；界面实现已拆分到 `client/gui`，NeoForge 改用 Kotlin for Forge，拆分后两端开发客户端均可启动到标题界面。自动展开、内置服务端命令模式、终端式输入历史与 `grep` 历史查询已接入；游戏内交互、局域网授权与视觉验证待完成，下一项功能是自动预览。

## 已实现

- `common`、`fabric`、`neoforge` 均已配置 Kotlin。两个平台的客户端入口调用共享的 `ConsoleClient.initialize()`。NeoForge 使用 Kotlin for Forge 6.5.0 提供 Kotlin 运行时，发布 JAR 不嵌入标准库。
- [ConsoleClient.kt](../common/src/main/kotlin/com/nts/ingamecnl/client/ConsoleClient.kt) 管理全局按键、面板状态、仅查看与自动展开叠加层生命周期；`gui` 包拆分控制台界面、日志排版/滚动、普通面板与叠加层绘制。[客户端 Mixin](../common/src/main/kotlin/com/nts/ingamecnl/client/mixin) 接入键鼠事件与原界面的恢复。
- 控制台首次打开以仅查看模式显示，同一客户端启动期间再次打开会恢复上次模式：仅查看叠加层占屏幕上方约 65%，不安装 `Screen`，世界中保持鼠标抓取，存档外鼠标点击穿透；翻页、回底、切换和关闭仍由键盘处理。按 Shift+Tab 进入日志或命令模式后，面板同样占约 65% 并接收键鼠输入。
- 开关、向上/向下翻页和回到底部四个按键注册到 `ingamecnl:console` 分类，可在原版按键设置中改绑；Shift+Tab 固定切换模式，Esc 固定关闭控制台。
- 关闭面板后重新打开，恢复本次客户端启动内最后使用的模式与未提交输入；日志与命令模式分别保存最多 200 条输入历史，↑/↓ 终端式调取，↓ 越过最新一条恢复当前草稿。客户端重启后回到默认仅查看模式。
- 面板可从主菜单、世界选择、聊天、物品栏和游戏中打开，包含顶部线性开合、10% 背景和 65% 高度，三种模式表现一致。日志与命令模式下波浪键写入输入框，仅查看模式下波浪键开关叠加层；进入世界时面板保持展开。命令模式始终在切换循环中；没有本地内置服务端时显示命令模式不可用提示。
- 接入 Cloth Config：Fabric 的 Mod Menu 配置按钮或 NeoForge 模组列表的配置按钮打开配置页面，可调整日志筛选、自动展开、日志颜色和仅查看叠加层的高度/动画时长/不透明度；配置保存到 `config/ingamecnl.json`，`filter` 命令与配置筛选保持同步。
- 自动展开以可见日志为输入：总开关默认开启，可见记录同时满足触发级别（默认 WARN）和可选关键词时显示只读叠加层，默认 25% 高度、停留 3 秒；新命中重新计时，Esc 可提前收起并进入默认 30 秒静默期，其他交互被放行。Esc 收起与静默期均可配置，静默期为 0 时禁用。手动控制台或配置界面打开时不触发；`autosplash filter <文本>` 可设置触发关键词。
- 阶段 2 接入 Log4j Appender、有界接收队列和原始历史。日志模式按接收序号显示 Loom 风格的日志行，支持自动换行、底部自动跟随、翻页、`End` 回底和新增记录计数。
- 日志模式的 `filter level`、`filter keyword`、`filter reset` 与 `filter show` 已接入。筛选规则以入队顺序生效，已显示的记录保持原样，隐藏记录仍保留在原始历史中。
- 日志模式的 `grep -k <关键词> -l <级别> [-t1 <开始>] [-t2 <结束>]` 查询提交时固定原始历史快照，在后台单线程按 1024 条分页扫描；结果按页发布，支持取消。结果只读、不插入后续日志、不触发自动展开；阅读区支持逐条/翻页/首尾/横向滚动与 q/Esc 关闭。
- 构建在 `:common:processResources` 前调用 Zig 交叉编译 Windows、Linux、macOS 的 x86_64/aarch64 comb 库，并全部打入两个平台的发布 JAR；ASCII 字段按 64 条一批走原生扫描，非 ASCII、超批容量、平台不匹配或原生加载/调用失败时回退 JVM。
- 命令模式通过专用命令会话执行：主机本地直接使用内置服务端控制台源，非主机客户端经局域网能力探测与主机授权后转发请求。命令在服务端线程执行，语法错误与执行异常转为反馈，结果写入有界命令时间线；局域网授权支持总开关、白名单/黑名单与玩家名/IP 匹配。

## 阶段 2 验证

`common` 的 Kotlin 编译、`fabric` 与 `neoforge` 的完整构建均已通过。Fabric 开发客户端可启动并显示默认仅查看叠加层、实时日志列表与筛选状态行，切换到日志模式后显示输入界面；Mod Menu 18.0.2 与 Cloth Config 26.1.154 均已加载，配置文件生成默认值。NeoForge 开发客户端通过 Kotlin for Forge 6.5.0 启动，加载 Cloth Config，配置入口已注册，未出现配置或元数据异常。配置页面由 Fabric Mod Menu 与 NeoForge 模组列表提供；颜色值已改为 RGB 并迁移旧配置。界面拆分与 Kotlin for Forge 改造后，Fabric 与 NeoForge 开发客户端均启动到标题界面；两端运行日志除 Mod Menu 在开发环境的图标提示外无异常。

待验证：

- 世界中仅查看模式的移动、视角和攻击/使用，以及存档外鼠标点击穿透。
- 四个按键改绑后的开关、翻页与回底行为，以及固定 Shift+Tab 切换、Esc 关闭。
- 日志/命令模式波浪键写入输入框、仅查看模式波浪键开关叠加层，以及进入世界时面板保持展开。
- 翻页、`End`、滚轮和新增计数在持续产生日志时的行为。
- 修改筛选后旧记录保持原样，新记录按新规则显示。
- 自动展开的级别/关键词组合触发、3 秒停留与新命中重新计时、Esc 提前收起、Esc 收起关闭后 Esc 交给游戏、手动收起后的静默期、其他键鼠放行，以及手动面板与配置界面打开时的抑制。
- 队列丢弃与历史淘汰计数。
- Fabric Mod Menu 与 NeoForge 模组列表配置入口、配置保存后筛选/颜色/叠加层参数与单人游戏授权参数的生效情况。
- 未开启作弊的单人存档中，命令模式由服务端控制台执行并回传结果；退出世界后时间线清空。
- 局域网非主机客户端的默认拒绝、总开关、白名单/黑名单、玩家名与 IP 匹配，以及主机本人始终可用。
- 仅查看模式首次展开的滑入动画、切换模式不重复播放动画，以及自动展开叠加层不显示标题。
- 关闭再打开恢复上次模式与未提交输入，日志/命令历史互相独立，↑/↓ 边界与当前草稿恢复正确。
- `grep` 查询只包含提交时历史、后续日志不插入、时间/级别/关键词交集正确，结果区滚动与 q/Esc 退出正常；查询期间历史淘汰不会让结果跳动。
- Windows x86_64 的 comb 库能从两个发布 JAR 提取加载，ASCII 查询走原生且结果与 JVM 一致；缺少对应平台库、非 ASCII 关键词和原生调用失败时自动回退。Linux/macOS 库已交叉编译进 JAR，仍需在对应系统实际加载确认。
- GUI 缩放、窗口尺寸变化与中文文案的视觉检查。
